강의 업로드

선택만으로 업로드하거나 처리하지 않습니다. 새 업로드마다 독립적인 임시 강의 세션을 만듭니다. 활성 탭의 heartbeat 동안만 음성/결과/대화를 보관하며, 세션 종료 시 즉시 접근 차단 및 로컬 삭제, 앱 관리 Object Storage 객체 삭제를 수행합니다. 진행 중 외부 호출/장애가 있으면 삭제를 재시도합니다. 비정상 종료 또는 모든 탭이 숨겨진 경우 임시 유예 후 만료됩니다. 새로고침은 종료가 아닙니다. 실제 모드는 NAVER Cloud로 자료를 전송하며 제공자의 자체 보관 정책은 별도입니다. 권한이 있는 음성만 제출하세요.

강의 질문
요약 완료 후 활성화됩니다. 근거가 부족하면 답변을 제한합니다. 응답 확인 대기 질문은 이 탭의 세션 저장소에 임시 보관하여 중복 전송을 방지합니다. 완료 확인·세션 종료 시 제거합니다. 같은 브라우저 탭들은 소유권을 공유하며 어느 탭에서든 종료하면 다른 탭에서도 사용할 수 없습니다.
